# 🚢 Titanic Survival Prediction

A machine learning project that predicts whether a passenger survived the Titanic disaster using a Random Forest classifier. This project uses the famous Titanic dataset and is ideal for beginners in data science.

---

## 🧠 Model Objective

Use passenger data (like age, gender, class, etc.) to predict if they **survived** (`1`) or **did not survive** (`0`).

---

## 📁 Files

- `titanic_survival_prediction.py` — main script for data processing, model training, and evaluation.
- `tested.csv` — dataset containing passenger details.
- `feature_importance.png` — plot showing the most important features in survival prediction (generated by the script).
